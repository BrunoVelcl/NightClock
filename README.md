# Nightclock

### About

Nightclock is an Android app that displays a clock on the phone’s screen at all times. It is designed for phones with
OLED or AMOLED displays, where unused pixels remain inactive, resulting in minimal power draw. Your phone becomes an
easy-on-the-eyes night clock, letting you quickly check the time when waking up in the middle of the night.
There are multiple fonts, colors, and time formats to choose from.

### Features

- Always-on night clock
- OLED / AMOLED optimized
- Multiple fonts and colors
- 12h / 24h time formats

### Note

Nightclock will work on any Android device, but on non-OLED displays it will not be power efficient, as the backlight
remains on while the app is running.
